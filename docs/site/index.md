# ImgData

ImgData ergänzt Synology Photos um Werkzeuge zur Analyse, Prüfung und Pflege von Foto-Metadaten und Gesichtszuordnungen. Rechenintensive Bild- und Gesichtsverarbeitung kann optional an externe Worker ausgelagert werden.
